# Mercato

Mercato is a simple e-commerce web application built to demonstrate core online shopping functionality, including product browsing, search, filtering, shopping cart management, and user interface pages.

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Storage:** Browser LocalStorage

## Features

* Product browsing and categorization
* Product search and filtering
* Shopping cart functionality
* Login and signup interfaces
* Product reviews and ratings
* Responsive design
* Basic Express.js REST API

## Project Status

Mercato is currently a **prototype/learning project**. Authentication, database integration, payments, and order management are planned for future development.
